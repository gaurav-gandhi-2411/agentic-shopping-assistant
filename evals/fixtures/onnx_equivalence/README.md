# ONNX equivalence fixtures

`queries.json`: the `text` field of the 60 frozen stage-2 retrieval-eval queries
(`evals/fixtures/retrieval/q01.json` .. `q60.json`, generated by `evals/retrieval/make_queries.py`,
seed 42), copied verbatim in file order from branch `feat/v4-retrieval-eval` at commit
`a6806cf96b9d0a99629f019f583b868fbe7667d0` (that branch is not merged yet, so the texts are
duplicated here to keep the gate runnable on `master`). Public product wording only; no personal
data. Used by `scripts/onnx_equivalence_gate.py` (criterion C4, rule
`evals/onnx_equivalence_rule.md`). If the query set is regenerated upstream this file does not
follow automatically: refresh it on purpose and re-run the gate.
